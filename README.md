# Jugglin

Jugglin is a standard-deck Tarock game for three or four, where every tarock has a twin and the Pagat beats the Fool.

👉 View the game on BoardGameGeek:  
https://boardgamegeek.com/boardgame/483309/jugglin

Designer Diary: https://boardgamegeek.com/blog/16873/blogpost/192927/jugglin-it-takes-three-to-tarock-wait-or-four

## Repository Contents

This repository contains:
- The official **rules** for both player counts (which include a player reference and a game board)
- A playingcards.io file for playing the game online
